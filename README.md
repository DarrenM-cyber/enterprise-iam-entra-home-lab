## Project Overview

This project involves designing and implementing a simulated enterprise Identity and Access Management (IAM) environment using Microsoft Entra ID.

The goal is to develop practical experience with enterprise identity administration, access controls, authentication security, identity monitoring, and governance.

The lab will simulate the identity environment of a fictional organization, Horizon Financial Services.

## Project Objectives

Demonstrate practical knowledge and hands-on experience in five core IAM areas:

1. **Identity Lifecycle Management**
   - Employee onboarding and offboarding
   - User provisioning and deprovisioning
   - Identity administration and automation

2. **Role-Based Access Control (RBAC)**
   - Security groups and role assignments
   - Least-privilege access
   - Permission management

3. **Authentication and Access Security**
   - Multi-Factor Authentication (MFA)
   - Single Sign-On (SSO)
   - Conditional Access
   - Privileged Identity Management (PIM)

4. **Identity Security Monitoring**
   - Sign-in log analysis
   - Suspicious authentication investigations
   - Identity risk assessment
   - Security incident documentation

5. **Identity Governance and Compliance**
   - User access reviews
   - Access control policies
   - Audit evidence
   - Security and compliance documentation

## Technology Stack

## Project Documentation

All configurations, procedures, PowerShell scripts, testing results, screenshots, and lessons learned will be documented throughout the project.

The objective is to demonstrate not only how IAM technologies work, but also how they support business security, operational efficiency, and regulatory compliance.

## Project Disclaimer

Horizon Financial Services is a fictional organization created solely for educational and portfolio purposes. All employee identities and organizational information used in this lab are simulated.

No real company or customer information is used.

## Learning Outcomes

Upon completion, this project will demonstrate hands-on experience implementing and managing identity and access controls in a simulated enterprise environment.
